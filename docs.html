Tài liệu Velclaw

Hướng dẫn kỹ thuật cho workspace Velclaw và các bề mặt liên quan trong repo này — từ cách chạy local đến quy trình deploy production. Xem thêm toàn bộ app/dự án con tại trang Hub.

Giới thiệu

Velclaw là không gian làm việc AI-native cho vòng đời phần mềm, gom 8 mảng: AI Agents, Workspace, Build, Runtime, Storage, GitHub, Deployment và Developer UI vào một nơi duy nhất.

ⓘ Repo velclaw-cli này chỉ chứa trang giới thiệu/tài liệu tĩnh (GitHub Pages). Mã nguồn sản phẩm Velclaw nằm ở repo riêng, private.

Bắt đầu nhanh

Chạy thử site tài liệu này ở local, không cần cài đặt gì ngoài một trình duyệt hoặc static server bất kỳ:

git clone https://github.com/zskbot/velclaw-cli.git
cd velclaw-cli
npx serve .

Để phát triển sản phẩm Velclaw (repo riêng, cần quyền truy cập):

git clone https://github.com/Velclaw/Velclaw.git
cd Velclaw && npm install
npm run dev

Quy trình Deploy

Deploy production chạy thủ công qua SSH, dùng GitHub Container Registry (ghcr.io) để lưu image và docker run trực tiếp trên VPS (không dùng compose), phía trước là Nginx + Certbot làm reverse proxy/SSL.

1. Build & push image

docker build -t ghcr.io/<owner>/<image>:<tag> .
echo $GHCR_TOKEN | docker login ghcr.io -u <owner> --password-stdin
docker push ghcr.io/<owner>/<image>:<tag>

2. Pull & chạy container trên VPS

ssh <user>@<vps-host> "docker pull ghcr.io/<owner>/<image>:<tag>"
ssh <user>@<vps-host> "docker stop <container-name> && docker rm <container-name>"
ssh <user>@<vps-host> "docker run -d --name <container-name> \
  --restart unless-stopped -p <port>:<port> \
  --env-file <path-to-env> ghcr.io/<owner>/<image>:<tag>"

3. Reload Nginx & health check

ssh <user>@<vps-host> "nginx -t && systemctl reload nginx"
curl -sSf https://<domain>/health
⚠ Lưu ý: đây là runbook thủ công, không có rollback tự động. Nếu health check thất bại, chạy lại docker run với <tag> của bản trước đó.

Xem bản trình bày trực quan (stepper + log mẫu) tại trang Deploy.

Checklist trước khi deploy

  • Đã chạy npm run build & type-check không lỗi
  • Token GHCR_TOKEN trên VPS còn hạn, đủ quyền read:packages
  • File --env-file trên VPS đã cập nhật biến môi trường mới
  • Tên container & port khớp với proxy_pass trong config Nginx
  • Đã backup volume dữ liệu nếu image mới có migration
  • Certbot còn hạn — kiểm tra bằng certbot renew --dry-run

Câu hỏi thường gặp

Trang này có phải mã nguồn Velclaw không?

Không. Đây là site tĩnh (GitHub Pages) giới thiệu và tài liệu hoá. Mã nguồn sản phẩm nằm ở repo private Velclaw/Velclaw.

Trang Deploy có tự động chạy không?

Không, đó là tài liệu minh hoạ quy trình thủ công, không kết nối tới hệ thống deploy thật.
