Build software with a controlled agent workflow.

01 · Architecture

CLI-first control plane cho software lifecycle.

01

Task Engine

Chuẩn hóa prompt, issue hoặc task local thành execution context có cấu trúc.

02

Executor

Chạy command và tool với input, output, exit code và log rõ ràng.

03

Review

Kiểm tra diff, test result và thay đổi trước khi cho phép promotion.

04

Gate

Quality và policy gates mang tính deterministic; gate fail thì workflow dừng.

05

GitHub

Kết nối branch, commit, pull request, review và status từ cùng một CLI.

06

Deployment

Đưa artifact đã được kiểm chứng sang deployment target theo policy.

03 · Quick start

Clone. Install. Execute.

Local development

$ git clone https://github.com/zskbot/Zvelclaw.git
$ cd Zvelclaw
$ npm install
$ npm test
$ npm start -- help

Docker

$ docker build -t zvelclaw .
$ docker run --rm zvelclaw help

# task workflow
$ zvelclaw task "implement login"
